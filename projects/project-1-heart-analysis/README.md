# Project 1: SASHELP.HEART Exploratory Analysis

## Overview

This project demonstrates exploratory and descriptive statistical analysis using SAS and the SASHELP.HEART dataset.

The project is designed as a Clinical SAS programming portfolio project and focuses on understanding patient-level clinical data, selecting appropriate statistical methods, analysing distributions, and interpreting SAS output.

## Objectives

- Explore the structure and characteristics of a clinical-style dataset
- Perform data quality and descriptive assessments
- Analyse categorical and continuous variables
- Assess distributions, skewness, and normality
- Select appropriate statistical tests
- Examine associations between clinical variables
- Generate interpretable tables and figures
- Document the complete SAS programming workflow

## Dataset

**Dataset:** SASHELP.HEART

**Source:** SASHELP library provided with SAS

The dataset contains patient-level information including demographic, lifestyle, and cardiovascular-related variables.

## SAS Procedures

The project will progressively use:

- PROC CONTENTS
- PROC PRINT
- PROC FREQ
- PROC MEANS
- PROC UNIVARIATE
- PROC SGPLOT
- Statistical association tests
- Additional procedures as required
